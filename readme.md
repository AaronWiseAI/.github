## 🚀 Projects

### [EVOLV](https://github.com/dxn111/EVOLV)
A self-evolving AI workspace. One Go binary that thinks, writes real components into its own source tree, and pushes them over WebSocket so the interface changes while you watch. No refresh, no rebuild, no restart. Local-first, no signup, works with Ollama or any API key, and keeps an append-only ledger of every change it makes to itself.

`Go` · `WebSocket` · `LLM tooling` · `Local-first`
